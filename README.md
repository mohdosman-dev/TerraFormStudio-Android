# Terra Form Studio - Mobile App

Android mobile client for the Terra Form Studio platform, designed for customers to discover and purchase artisan-crafted goods.

## Features

- **Product Discovery**: Browse by materials, techniques, or curated collections.
- **Artisan Stories**: Learn about the people and processes behind each piece.
- **Seamless Checkout**: Native mobile shopping experience.
- **Real-time Notifications**: Updates on order status and new collection drops.

## Tech Stack

- **Language**: Kotlin
- **Build System**: Gradle
- **Architecture**: MVVM
- **UI**: Jetpack Compose (Assumed based on modern standards)

## Setup and Installation

### Prerequisites
- Android Studio (latest version recommended)
- Android SDK
- Java Development Kit (JDK) 17+

### Installation
1. Clone the repository and navigate to the mobile directory:
   ```bash
   cd TerraFormStudio
   ```
2. Open the project in Android Studio.
3. Allow Gradle to sync and download dependencies.

### Running the App
- Select a physical device or emulator.
- Click the "Run" button in Android Studio or use `./gradlew assembleDebug`.

## Configuration
Update the `local.properties` or appropriate configuration file with the base URL of your backend API.
